# QUICK CRAVE — Malvani Coastal Seafood

A minimal, high-conversion food website for **QUICK CRAVE**, an authentic Malvani coastal seafood brand available on **Zomato**.

Inspired by clean, modern food-tech web design (e.g. *Impossible Foods* on Mobbin), this revamp removes unnecessary clutter, blocking loading screens, and audio gimmicks, focusing purely on:
- **Interactive 3D Dish Experience** (Three.js & GSAP) with real-time model switching (Pomfret Fry, Surmai Special, Malvani Handi), pointer tracking, and floating coastal spices.
- **Impossible Foods Mega-Category Showcase**: Signature bold pill navigation and multi-column dish list with instant item spotlights.
- **Complete Flyer Menu**: All 19 authentic dishes from the physical menu across Chef's Specials, Main Courses, Feast Combos, and Drinks with exact pricing in ₹.
- **Direct Zomato & Contact Integration**: Instant "Order on Zomato" actions and direct hotline lines (`9920404232` / `022 31520888`).
- **Streamlined Cart & WhatsApp Ordering**: Fast drawer checkout with instant WhatsApp order generation.

## Tech Stack
- **React 18 & TypeScript**
- **Vite**
- **Three.js & @react-three/fiber**
- **GSAP** (GreenSock Animation Platform)
- **Tailwind CSS**
- **Zustand**
- **Lucide Icons**

## Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
